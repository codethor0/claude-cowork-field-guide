# Exercises

Last reviewed: 2026-11-22

Seven original exercises that follow the course's arc: delegate a task, control permissions, automate, add standing context, build skills, review plugins, and work safely on the web. All input data is synthetic and lives in [examples](../examples/practice-folder/file-list.csv).

Each exercise has an objective, prerequisites, input data, a copy-ready prompt, expected result characteristics, a verification checklist, common failure modes, and a follow-up. Generated output varies between runs, so the exercises describe what to look for, not exact text.

|---|---|---|---|
| 1 | [First delegated task](01-first-delegated-task.md) | [Delegating a task](../docs/delegating-a-task.md) | Yes |
| 2 | [Choose the permission mode](02-choose-the-permission-mode.md) | [Permissions and modes](../docs/permissions-and-modes.md) | No |
| 3 | [Design a scheduled briefing](03-design-a-scheduled-briefing.md) | [Scheduled tasks](../docs/scheduled-tasks-and-remote-access.md) | No |
| 4 | [Write standing instructions](04-write-standing-instructions.md) | [Instructions, projects, and memory](../docs/instructions-projects-and-memory.md) | No |
| 5 | [Build and test a skill](05-build-and-test-a-skill.md) | [Skills](../docs/skills.md) | No |
| 6 | [Review a plugin](06-review-a-plugin.md) | [Plugins](../docs/plugins.md) | No |
| 7 | [Plan a safe browser task](07-plan-a-safe-browser-task.md) | [Browser and computer use](../docs/browser-and-computer-use.md) | For part C only |

Use a dedicated practice folder with copies of files. Never use real financial, medical, or personal data in an exercise.
