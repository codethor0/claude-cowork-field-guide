# Weekly status report

## When to use

The user asks for a weekly status, weekly recap, or end-of-week summary and provides meeting notes for that week.

## Steps

1. Read every note for the week. Do not use notes from other weeks.
2. Extract decisions, risks, action items (with owner and due date when stated), and open questions.
3. If a later note resolves an earlier risk or question, report the resolution, not the original item.
4. Write the report in the format below. Keep it to one page.
5. List any note that could not be read or seemed incomplete.

## Format

- Title: "Status: week NN"
- Sections, in order: Summary (three sentences at most), Decisions, Risks, Actions, Open questions, Sources.
- Actions as a table: action, owner, due.
- Sources: the file names used.

## Rules

- Do not invent owners or dates. Write "not stated".
- No names beyond those in the notes.
