# Sample project instructions

Synthetic example for Exercise 4. Project instructions apply only to tasks inside one project, so they hold the rules for that body of work.

```text
Project: monthly volunteer newsletter.
Audience: current volunteers and donors. Reading level: general public.
Length: 400 to 600 words. Sections in this order: highlight, upcoming
shifts, thank-yous, how to help.
Never include volunteers' surnames, phone numbers, or addresses.
Quotes need a note in the draft saying whether consent is recorded.
Save drafts as newsletter-YYYY-MM-draft.docx in the project folder.
```
