# Sample global instructions

Synthetic example for Exercise 4. Global instructions apply to every Cowork session, so they hold only durable preferences.

```text
I coordinate volunteers for a small nonprofit. Write in plain English for a
general audience. Prefer short paragraphs and bulleted lists. Use ISO dates
(YYYY-MM-DD). When a task produces a file, tell me its name and location at
the end. Ask before deleting, moving, or renaming anything outside the
folder I named in the task.
```
