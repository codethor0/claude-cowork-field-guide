# Microsoft 365 add-ins

Last reviewed: 2026-11-22

## What they are

Anthropic's product page describes Claude add-ins that work inside Excel, PowerPoint, Word, and Outlook, with context that carries from one app to the next. The statements below come from that page and the Help Center; this guide did not test the add-ins hands-on.

| Add-in | What the product page says it does |
|---|---|
| Excel | Answer questions about cells, update assumptions without breaking formulas, build models |
| PowerPoint | Build slides in your template, edit a selection, generate native charts and diagrams |
| Word | Edit with tracked changes, respond to comment threads, apply company styles |
| Outlook | Triage the inbox, draft replies that wait for you to send, find meeting times |

## How they fit with Cowork

Per the Help Center, Cowork can produce spreadsheets and slides that you then keep editing with Claude for Excel and PowerPoint. Skills can also be used inside the Microsoft 365 add-ins.

## Cross-app data sharing

The Help Center notes that when the Excel and PowerPoint add-ins are used with Cowork, Claude can read, edit, and pass context between the applications, for example moving a chart from a workbook into a deck without being told to. Before you start:

- Know which open workbooks, decks, and documents contain sensitive data.
- Close files that should not be part of the task.
- Review tracked changes and drafted emails before accepting or sending them.

## A safe working pattern

1. Draft or analyze in the add-in with the minimum set of files open.
2. Keep Word edits as tracked changes so every change is visible.
3. Treat drafted emails as drafts. You send them, after reading them.
4. Check formulas and totals in any model Claude builds or changes.
