# Security policy

This repository contains documentation, synthetic example data, and small Python validation scripts. It has no server, accounts, or credentials.

## Reporting a problem

Report a security concern privately using GitHub's "Report a vulnerability" option under the repository's Security tab. If that option is unavailable, open an issue that says only that you have a private security report, without details, and the maintainer will arrange a private channel.

Relevant reports include:

- A secret, personal data, or confidential material committed to the repository or its history.
- A vulnerability in `scripts/` or in the GitHub Actions workflow.
- Guidance in the documentation that would lead readers to an unsafe configuration, such as over-broad permissions or unsafe browser use.

## Response

This is a solo-maintained project. Reports are handled on a best-effort basis with no guaranteed response time.

## Scope

Vulnerabilities in Claude, Claude Cowork, or other Anthropic products are out of scope. Report those to Anthropic through its official channels listed at <https://www.anthropic.com/legal>.
